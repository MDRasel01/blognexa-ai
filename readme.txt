AI-powered WordPress content intelligence and blog automation platform.

== Description ==

BlogNexa AI is an enterprise-grade WordPress content intelligence and blog automation plugin.
It connects your WordPress website to a secure cloud AI backend to discover site intelligence,
build a persistent knowledge base, research keywords and competitors, and generate high-quality,
research-backed SEO articles with human editorial approval workflows.

== Installation ==

1. Upload the `blognexa-ai` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Access the BlogNexa AI menu in your WordPress Admin sidebar to connect your site and configure settings.
